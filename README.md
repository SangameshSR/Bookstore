# Online Bookstore Application

A full-stack Online Bookstore web application developed using Java Spring Boot for the backend and HTML, CSS, and JavaScript for the frontend.

## Features

- View available books
- Add new books
- Update book details
- Delete books
- REST API integration
- Responsive user interface
- Maven project structure

---

## Technologies Used

### Backend
- Java
- Spring Boot
- REST API
- Maven

### Frontend
- HTML
- CSS
- JavaScript
